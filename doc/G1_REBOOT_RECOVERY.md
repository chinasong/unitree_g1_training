## 使用方式

双击 `连接G1只读控制台.command`，保持窗口运行，浏览器入口为 <http://127.0.0.1:18765/>。已有恢复进程时直接使用该页面，不重复启动。

```bash
.venv/bin/python scripts/connect_orin_console.py --open
```

密码仅在设备指纹核验后请求，在本进程内存中用于自动重连，退出后清除引用；不写入项目文件或 SSH 配置。`.g1-console/connection.json` 仅记录核验地址、固定指纹与网络元数据，且已忽略。进程退出或 Mac 重启后需重新打开入口；未新增登录项或全局后台服务。

本轮补齐重连后的开机诊断：boot ID、IP、NetworkManager 自动连接元数据、无线驱动、RF-kill、SSH enabled / active / TCP 22 监听状态、网络服务状态及本次开机日志的故障类别。读取先于项目服务恢复，项目或 DDS 未就绪时仍保存取得的诊断。命令缺失、权限不足、超时和空日志保留未知；自动诊断不保存原始 SSID、密码或认证内容，零匹配不解释为不存在故障。本次实机已取得新开机诊断回执；深入排障的原始日志仅保留在被忽略的本机研究目录，项目证据已筛选。

发现 Orin 后的流程：核验 SSH 身份 → 核对 Orin 平台 → 检查项目服务 → 必要时核验现有发布并启动 → 核对只读配置 → 仅对本次新启动的空闲服务初始化 DDS 读取 → 开放转发 → 持续检查项目 HTTP 链路。

恢复只使用项目目录 `/home/unitree/workspace/g1-body-console` 的已有运行时和发布，不安装依赖，不更新官方程序。已有服务不会被终止、抢占或切换模式；已有显式断开状态保持不变。项目进程还在启动时不会重复拉起。恢复启动采用项目内文件锁与清单 SHA256 校验。

软件遥控启动器显式使用人工模式，但恢复也不获取 owner、不授权运动、不重放动作。断线请求立即失败；控制权、导航与动作没有恢复队列。
