## 7301 与固件的结论边界

官方 [G1 错误头文件](https://github.com/unitreerobotics/unitree_sdk2/blob/main/include/unitree/robot/g1/loco/g1_loco_error.hpp)将 7301 定义为 **LocoState not available**，未提供对应服务端内部判定。FSM 0、ai_sport 开启与 7301 在本窗口同时出现，只能确认相关性，不能证明 FSM 0 是充分或必要触发条件，也不能推断切换模式或重启服务可以解决。

官方 [G1 服务状态接口](https://support.unitree.com/home/en/G1_developer/robot_state_client_interface)定义回读 status 0 为开启、1 为关闭；服务开启不等于 LocoState 就绪或平衡安全。`device_motion_firmware`、`exact_7301_predicate`、`balance_ready` 均保持 `null`。

App 关于设备 v1.5.6、硬件 v1.0、PC4 master/patch/video 版本、SDK 协议及缓存包名称都不代填 ai_sport 版本。官方仓库 issue [#43](https://github.com/unitreerobotics/unitree_sdk2_python/issues/43)的历史报告提到 App 的“设备 → 服务状态 → ai_sport”组件版本，但属于其他机器人，不能抄作本机值。剩余所需证据是本机该字段，或宇树提供的、与 `.161` 实际应答匹配的只读版本契约及 7301 服务端说明。
