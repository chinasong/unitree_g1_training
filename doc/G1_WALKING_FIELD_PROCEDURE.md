# G1 软件遥控行走 · 现场流程（阶段 A）

2026-10-22 编写，尚未实机执行。驾驶页提供**一键启动 / 一键停止**：按官方手册路线（[mode_sequence.py](../g1_console/mode_sequence.py)）自动串联模式，每步等双路回读到目标 FSM、关节静止后才进入下一步；任一步异常即停在原地，不重试、不自动回退。单独的模式切换按钮仍锁定；阻尼保护（对应手册 L2+B）对持有控制权的窗口随时开放，按住 0.8 秒触发。实体遥控器全程在手，作为后备。

本流程不建立"不会摔倒"的结论。每次执行分别报告四件事：代码是否就绪、是否已部署、请求是否被官方服务接受、机器人是否实际完成动作。

## 0. 前置条件

| 项 | 要求 |
| --- | --- |
| 人员 | 至少两人：一人持**实体遥控器**并全程站在机器人旁；一人操作 Mac。实体遥控器持有人有权随时叫停 |
| 保护 | 吊架或专人扶持待命。软件授权前须确认吊绳**松弛不承重**、扶持的人**已松手**（界面要求勾选"没有外部支撑"） |
| 场地 | 平整地面，机器人四周和行进方向至少 2 m 净空，无台阶、边缘、线缆 |
| 电量 | 依官方手册要求；低电量不执行 |
| 急停 | 实体遥控器的阻尼保护组合键（以本机固件版本手册为准）。软件"停止"只发送零速度，**不是急停** |
| 资料 | 官方 23 DOF 遥控手册：G1_REMOTE_CONTROL_23DOF_20260407.pdf（官方 PDF 未随公开仓库发布，请从宇树官网获取）。按本机固件对应分支的步骤操作，手册以外的按键不尝试 |

## 1. Mac：把服务切到完整人工遥控范围

当前默认运行范围是单次阻尼测试（`damping`），软件行走需要完整人工遥控范围（`manual`）。

1. **关闭正在运行的连接窗口**（`连接G1软件遥控器.command` 等）。如果连接器还在运行，部署工具会拒绝执行，以免旧连接器在重启窗口内按旧范围恢复服务。
2. 如果代码在上次打包后有改动，先重新构建并打包：

   ```bash
   cd console/web && npm run build && cd ../..
   .venv/bin/python scripts/package_orin_console.py
   ```

3. 部署并切换范围。终端会先核验 Orin 主机指纹，再提示输入 SSH 密码：

   ```bash
   .venv/bin/python scripts/deploy_orin_console.py --scope manual
   ```

   部署工具按以下顺序执行，任一步失败就停下：
   1. 检查现有服务是否空闲（无控制者、未授权、导航空闲）；
   2. 上传发布包并逐文件校验 SHA256；
   3. 只停止事先核验过 PID 和启动时间的本项目进程；
   4. 激活新发布并按目标范围重启；
   5. 核对运行中的发布、运行范围、空闲状态，以及阻尼凭据 `state/damping-test.json` 是否原样保留。

   新发布启动失败时会自动回滚到原发布和原范围。每次运行的记录写在 `.g1-deploy/research/deploy-*.json`。
4. 双击 **`连接G1软件遥控器（行走）.command`**。它只接受完整人工遥控服务；如果遇到接口验证、声光或阻尼等受限范围的服务，会拒绝转发。
5. 打开页面，确认处于人工遥控模式、无控制者，且 23 个关节和相机都在线。

## 2. 现场：一键启动到行走模式

| 路线 | 起始姿态 | 自动步骤 |
| --- | --- | --- |
| 座椅（官方推荐） | 端坐椅上、双脚着地，FSM 0 或 1 | **一键启动与一键停止均未开放**：FSM 4 与手册 ② 的对应未核定（2026-10-22 发送后倾倒，见[复盘](G1_SEQUENCE_TIP_20261022.md)），FSM 3 落座无官方示例、座椅条件无法由传感器确认。用实体遥控器 |
| 蹲姿 | 双脚着地蹲姿，FSM 0 或 1 | 阻尼 → 蹲站起立（FSM 706）→ 进入行走（FSM 500，固件已自动进入时跳过） |

每步除双路回读和关节静止外还检查姿态：任一时刻 \|roll\| 或 \|pitch\| > 0.8 rad 立即中止；站立类步骤结束时须 ≤ 0.35 rad。躯干倾斜时拒绝一键启动（> 0.8 rad）和一键停止（> 0.35 rad），倒地后的复原交给实体遥控器。

哪些模式可以进入自动串联由 `mode_sequence.EVIDENCE` 决定：只有官方 G1 示例同样用法或本机已回读验证的调用才开放，候选映射一律不进执行路径。任一电机温度 ≥ 70 ℃（项目拦截线）时拒绝一键启动，运行中达到即中止；一键停止不因温度拦截。驾驶页同时显示温度告警。

躺姿路线需要手册 ⑩ 自适应起身，公开 SDK 没有已核实的入口，软件不提供。**当前坐地靠柜姿态不属于任何一条路线**，先人工把机器人摆到路线起始姿态。

1. 吊架或扶持就位。在 Mac 另一个终端启动 7301 对照采样（只读）：

   ```bash
   .venv/bin/python scripts/compare_g1_locostate.py --duration 600 --interval 2 --note "一键启动：<路线>/<保护方式>"
   ```

2. 驾驶页选路线 → **一键启动** → 逐项勾选（起始姿态 / 保护就位 / 周围净空 / 实体遥控器在手）→ 确认并启动。页面会自动取得控制权。
3. 进度卡逐步显示。座椅路线停在“人工扶直”时，由现场人员扶直扶稳，再点 **已扶直，进入行走**（60 秒内不点则中止，保持锁定站立）。
4. 到达 FSM 500 后，页面自动弹出驾驶前的四项确认，进入第 3 节。
5. 任一步超时或异常，进度卡显示原因，机器人停在当前模式。用实体遥控器接管，不要在软件里反复重试。

## 3. 软件接管：按住行走

1. 实体遥控器的摇杆**回中、不再操作**，但遥控器继续拿在手里。软件和实体遥控器同时下发速度时，以哪个为准没有核实过。
2. 吊绳放松到不承重，扶持的人松手、退到不在行进方向上的位置。
3. 页面"软件遥控器"：
   1. 点 **取得本窗口控制权**；
   2. 在"人工现场确认"中逐项勾选四项（已自行站立 / 没有外部支撑 / 四周净空 / 地面平整），点 **启用人工遥控 · 60 秒**。授权 60 秒后自动过期，需要重新确认。
4. "操作速度"选 **缓速 · 50%**。第一次只做：
   1. 按住"向前"约 1 秒后松手，观察是否停稳；
   2. 原地左转、右转各约 1 秒；
   3. 点"停止行走"。
5. 每一步都记录：页面上的请求结果（接受 / 拒绝 / 错误码）、FSM 回读，以及肉眼看到的动作是否完成、是否稳定。

## 4. 中止条件

出现以下任一情况，**持遥控器的人立即用实体遥控器保护**，Mac 端点 **立即锁定人工遥控**：

- 身体明显倾斜、踉跄、单脚离地异常，或关节温度告警；
- 页面回读过期、FSM 不是 500，或请求返回 3104 / 7301 以外的未知错误；
- 软件松手后机器人没有在约 0.5 秒内停下；
- 有人或物进入行进方向。

软件端的兜底：松手、窗口失焦、心跳中断、遥测超过 0.6 秒未更新、速度指令超过 0.25 秒没有续发，都会自动发出停止。这些都依赖网络，不能替代实体急停。

## 5. 结束与复原

1. 驾驶页选同一路线 → **一键停止**（目前仅蹲姿路线开放；座椅路线用实体遥控器） → 逐项勾选（座椅已放回身后 / 下蹲空间清空、保护就位、净空、遥控器在手）→ 确认。自动执行：停止行走 → 落座（FSM 3）或站姿下蹲（FSM 706）。
2. 机器人到达终点姿态后，现场人员扶持或吊住，再按手册关机。
3. 结束对照脚本（Ctrl-C），记录原始文件路径。
4. 关闭行走连接窗口，把服务切回默认的单次阻尼范围：

   ```bash
   .venv/bin/python scripts/deploy_orin_console.py --scope damping
   ```

5. 把结果写入当天的验证文档：时间、保护方式、每一步四级证据（代码 / 部署 / 接受 / 完成）、对照脚本结论、未知项。
