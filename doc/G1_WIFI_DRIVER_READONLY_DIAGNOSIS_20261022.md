- 已安装模块：`8852bu`，版本 `v1.19.3-45-g7583a804a.20230505`，内核 `5.10.104-tegra`。
- 本机 DKMS 源码：`/usr/src/rtl8852bu-1.19.3`，版本头匹配；DKMS source 链接指向同一目录。安装模块与 DKMS 构建目录中的模块 SHA256 一致：`4a5c04932df776166e9af87bf0528c1b858a74f134824a2566b0a6946f918f47`。这提供版本和产物关联，未重新编译证明源码可复现同一二进制。

| 本机源码位置 | 对报错的解释 |
| --- | --- |
| `phl/hal_g6/phy/bb/halbb_fwofld.c:147–166` | `halbb_fw_set_reg` 构造 BB 寄存器写命令，调用 `rtw_hal_mac_add_cmd_ofld`；非零就输出 IO offload fail |
