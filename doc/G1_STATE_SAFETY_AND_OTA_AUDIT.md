## 当前状态如何学习

`GET /api/state` 新增 `assessment.state_learning`，由本机确定性规则生成，独立于暂停中的 Mac 视觉观察 worker。

| 输出 | 证据和限制 |
| --- | --- |
| 官方控制模式 | 只使用新鲜 GetFsmId；固定 SDK 将 0 映射为 ZeroTorque、500 映射为 Start。未取得具体动作执行中/完成反馈，active_capability_id 保持 null |
| 关节形态 | 膝角度和 IMU 横滚/俯仰来自新鲜反馈；双膝 >90° 仅描述为“显著屈曲”，不是安全阈值 |
| 世界中的姿势 | 不从关节角或三维模型猜测站/坐/卧、身体高度、足底承重或外部支撑；均保留未知 |
| 12 秒变化窗口 | 只统计不同 received 时间的样本；断流、重连、坐标/机型模式改变时清空。不把角度极值、静止或“观察期间没摔倒”当安全集 |
| 历史学习记录 | 实机新鲜反馈每 30 秒写入本项目的 events.jsonl；带 run、wall time、tick、foundation_id、模式、形态和窗口。current=false、execution_allowed=false；重启后不恢复为当前状态或动作权限 |

FSM 是控制服务回读 ID，不能证明具体官方能力正在应用；FSM 0 也不能证明每个电机实际力矩为零。演示、缺失、过期或非有限反馈不作为新鲜实机证据。

## 安全知识与未来任务策略

基础档案 `state_safety` 持久保存三类信息：官方 SDK 参考默认值、本项目软件拦截线、尚缺少的实机与现场证据。这些类别不互相代替。

官方 [terminations.hpp 固定版本](https://github.com/unitreerobotics/unitree_sdk2/blob/d1abf001220d3e5f59e00a0c4aaa595e00089a4a/include/unitree/robot/g1/common/terminations.hpp) 有 7 个可覆盖参数的辅助函数：方向角 1 rad、关节速度 10 rad/s、机体角速度 6 rad/s、绕组温度 120°C、外壳温度 85°C、SOC 20%、失联 1000 ms。**它们是源码默认参数，不是从这台机器人读出的保护阈值，也不是不会摔倒的工作范围。** 没有运行这些函数或采用其注释建议发送卸力。

本项目现有的 0.6 秒遥测、1.5 秒 FSM、0.35 rad 横滚/俯仰、70°C 电机温度及速度输入限制同样只是软件拦截条件。通过检查不授予运动权限。界面逐项显示：

1. 真实完整身体反馈、行走候选模式、项目姿态和温度检查。
2. 足底接触/承重、动态平衡裕量、地面/摩擦/净空。
3. 实机限值/标定、驱动健康/降额/电池。
4. 防跌落保护、官方控制归属、失联/急停行为。
5. 每项具体能力的进入、全过程、退出/打断与恢复条件。

后 7 项目前没有足够证据，持续显示未知。不存在可从当前传感器和文档确定的“永不摔倒”范围。先补齐证据，再为具体官方能力实现并审查验证器；真实动作验证还需另行授权和现场保护。本轮只做被动观察。

`ConsoleService._rpc` 在实际适配器调用前拒绝所有真实运动、姿势/模式切换和手臂动作；切换 read_only、持有租约或人工勾选地面条件均不能绕过。未来可写服务保留原有停止行走分发路径；当前强制只读连停止、声光写入也拒绝。停止行走不等于通用急停或卸力。本轮没有调用任何动作。

验证记录见 [G1_STATE_SAFETY_VERIFICATION.json](G1_STATE_SAFETY_VERIFICATION.json)。测试使用进程内假适配器检查最终运动出口，并用正常查询/停止的假调用作正向对照；无实机动作试验。前端包含原有 3D 大资源提示。部署只重启本项目只读控制台，官方服务、暂停中的 Mac observer、Quantumult X 和系统网络均不修改。
